# Site Juno Importadora

Site institucional B2B da Juno Importadora: perfumaria árabe de luxo (Le Bonheur, Orientica, Armaf, Hamidi e Manasik) para lojistas e revendedores.

- Site: pasta `juno/` (HTML, CSS e JS puros, sem build)
- `index.html` na raiz redireciona para `juno/`, mantendo a rota já indexada no Google (`/juno/`)
- `.htaccess`, `robots.txt` e `sitemap.xml` para a hospedagem no domínio junoimportadora.com.br

## Publicação
- **GitHub Pages**: publicado a partir da branch `main`, pasta raiz.
- **Domínio próprio (Locaweb)**: veja `LEIA-ME_publicacao.txt`.

Fotos de produtos: fontes registradas no banco de imagens da Juno. Fotos de ambientação: Pexels (licença de uso comercial livre).
